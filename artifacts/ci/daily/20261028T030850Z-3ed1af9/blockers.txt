Why the work stops, in the order it costs time

  1. The verification pass competes with the work for the same hours. (no daily run is recorded in artifacts/ — the sandbox wipes it — so the durations published in docs/10 §5 and §11 are the only ones this report can quote)
     Re-proving what was already proved is not free: a loop that pays it every round
     builds less than a loop that builds and hands the proving to one daily job, which
     is what tool/ci/daily.sh exists for and why the checks are collected into an
     artifact instead of being run inline.

  2. The sandbox is rolled back between turns, and the rollback is not visible in the
     repository. Section E is the signature: node_modules and artifacts/ wiped, and the
     local .git reset to the branch point so the pushed work is present only as
     uncommitted files — which then look like new work and can be committed over the top
     of themselves. It has happened repeatedly on this branch, most recently at the start
     of the turn that produced this report, and the repository cannot show a history of it
     because the rollback removes the evidence too. Each occurrence costs a fetch, a
     mixed reset, an npm ci and a re-run of the suite before anything new is written.

  3. What is left is not code that can be written here. Sections A-D are the reason: no
     Dart or Flutter toolchain and no pub.dev, so the authoritative engine can never be
     compiled on this machine; no radio, no handset, no macOS host; CI refused for
     billing, so nothing is verified remotely either. Section F puts a number on it: of
     the 28 open roadmap items, 0 can be closed from here, and the other
     28 need hardware, a store account, a toolchain, or fifteen people in a quad.
     skills/08 already forbids claiming large-scale results without that crowd test, so
     the remainder is not deferred code. It is the part of this project that was never
     going to happen inside a container, and the honest output here is the specification,
     the simulator, the checks and the measurements for whoever has the phones.
